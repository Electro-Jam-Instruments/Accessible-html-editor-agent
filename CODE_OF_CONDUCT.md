# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful; harassment and personal attacks are not tolerated; critique
evidence and code, never people. This project measures other teams' work and publishes
scores, so one house rule carries extra weight here: **findings are stated about editors
at pinned commits, never about the people who build them.** The editors measured here are
well-built tools by teams who care; the corpus exists to make a gap visible, not to rank
engineers.

Report unacceptable behaviour by opening an issue, or — where the report concerns another
participant — by contacting the maintainers privately through GitHub. Maintainers will
respect the privacy and security of anyone who reports an incident.
